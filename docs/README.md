# 자동차 경주 게임 구현

## 제약사항

- indent(인덴트, 들여쓰기)는 2까지만 허용한다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라. → SOLID 원칙의 SRP 준수
- JUnit 5와 AssertJ를 이용하여 본인이 정리한 기능 목록이 정상 동작함을 테스트 코드로 확인한다.
- 클린 코드를 지향한다.

## 게임 진행 조건

## Input

**자동차 이름**
- [ ] 쉼표로 다른 자동차를 구분한다.
- [ ] 이름은 5자 이내이다.
- [ ] 중복된 이름과 공백을 허용하지 않는다.
-

**이동 횟수 입력**
- [ ] 입력 값은 0 이상의 int 값이다.
- [ ] 값을 기준으로 차수별 게임이 진행된다.

**예외 처리**
- [ ] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 애플리케이션을 종료시킨다.

**자동차 전진 조건**
- [ ] 0 ~ 9사이의 랜덤한 값을 생성한다.
- [ ] 값이 4 이상일때 전진한다.
- [ ] 사용자가 입력한 횟수만큼 반복한다.
- [ ] 반복 횟수는 최소 1회 이상이다.

## Output

**안내 메시지**
- [ ] 게임 시작 시 `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)` 안내 문구를 출력한다.
- [ ] 자동차 이름 입력 이후 `시도할 회수는 몇회인가요?` 안내 문구를 출력한다.

**차수별 진행 결과**
- [ ] 각 자동차의 전진 유무는 "-" 로 출력한다.
- [ ] 각 자동차의 진행도는 줄마다 분리하여 `carName : ---` 형식으로 출력한다.

**게임 완료**
- [ ] 게임 완료 후 우승자를 출력한다.
- [ ] 우승자는 1명 이상이다.
- [ ] 2명 이상일 경우 쉼표로 우승자를 구분한다.

**예외 처리**
- [ ] 예외가 발생한 상황별 메세지를 출력한다.
